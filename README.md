## Codex 汉化包介绍

Codex 汉化包（ChatGPT 汉化启动器）是一个给 ChatGPT 和 Codex 桌面端换中文界面用的小工具，完全免费，不用注册账号，不用登录，下载安装完打开就能用。打开它点一下按钮，官方客户端的界面就自动切成中文，之后每次从它这里打开都是中文，不用手动改任何设置。

它不动官方客户端的文件，不替换也不重新打包。官方软件该更新还正常更新，只是在你启动的时候顺手把中文打开。以后官方升级了，启动器会自动跟着适配，不用你去找新汉化包，也不用重装；要是新版本还没适配，它会先保留英文界面并提示你等一等，不会硬塞一份旧中文进去把软件弄坏。

## 安装步骤

### 第一步：下载并安装

双击下载好的安装包，一路下一步。它按当前用户安装，不用管理员密码，也不会往系统目录里写东西。装完桌面上和开始菜单里会出现「ChatGPT汉化启动器」。装完就能用，不用重启电脑，也不用另外配置环境。

### 第二步：点一下按钮切换中文

打开启动器，它会先认机器上的官方客户端，认完把客户端版本写在状态条上，接着点界面中间那个按钮。

- 第一次打开，按钮上写的是「关闭并以中文工作台重启」。点下去官方客户端会被关掉，再以中文工作台重新拉起来。
- 以后打开启动器，按钮上的字变成「重新启动中文工作台」，效果和第一次一样。

按钮下方有一行提示，重启会关闭当前客户端窗口，点之前把手头的东西存一下。客户端重开之后界面就是简体中文，翻到设置里看一眼语言确认一下就行。

### 第三步：以后从启动器打开 Codex

Codex 官方客户端不支持永久汉化，重启电脑之后界面就会恢复成英文。所以每次用的时候，记得从启动器里进 Codex，它会把中文资源重新打开一次。启动器平时待在系统托盘里，只有右键点退出才会真退出，关掉窗口不算。

## 汉化包导入方法

不需要手动导入。下载下来的就是一个安装包，不用再去别处找语言包，也不用单独导入任何文件。

汉化启动器做的事只有一件：在客户端启动之前，把 `desktop.localeOverride = "zh-CN"` 写进官方配置，让客户端启动的时候读到中文。这个动作在后台自动完成，你在界面上看到的就是一个按钮。

它不替换官方文件，也不重新打包客户端，只是借官方自己留的那个运行时开关，把客户端里本来就内置的中文资源打开。所以官方客户端该更新照常更新，签名和校验都不受影响，装汉化不等于改客户端。

## 常见问题

**装完没反应？** 十有八九是客户端版本或安装渠道对不上。汉化启动是去识别本机已经装好的官方客户端，认出来才能接着往下走。Windows 这边有微软商店版和传统安装包两种，macOS 常见 ChatGPT.app 和 Codex.app 两个名字，先分清自己装的是哪一个，再去对版本。

**官方更新完汉化就没了？** 这不是汉化被官方修掉了，而是版本变了，原来那套对应关系跟不上了。启动器每次启动前会先比一次官方版本，需要适配就自己更新，你这边不用重新找包，也不用重新下载重装。新版本还没进兼容清单时，它会保留官方原来的界面并提示等适配。

**要不要为了汉化去装旧版本客户端？** 不要。旧版本拿不到新的模型和修复，捡了芝麻丢了西瓜。版本往前走，汉化跟着走，这样更顺。

**界面还是英文，能不能先用？** 能。界面语言和回复语言是两件事。菜单栏、设置页是界面语言，归客户端管；你问一句它回一段，归模型和你的提示词管。界面挂着英文的时候，你完全可以让它全程用中文回答、解释代码、分析报错。

**怎么看生效没生效？** 界面变成中文就是生效了，菜单、设置页、侧边栏最直观。没变的话，先看工具里给出的适配状态，状态写着未匹配说明你的版本还没进清单，这时重装也没用，等清单更新更直接；状态正常但界面还是英文，可以把运行日志里最后一行发给我们。
