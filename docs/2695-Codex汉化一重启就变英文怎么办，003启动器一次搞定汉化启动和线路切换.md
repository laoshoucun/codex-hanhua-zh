# Codex 汉化一重启就变英文怎么办，003 启动器一次搞定汉化启动和线路切换

> 原文链接：[https://www.sz003.com/codexh/2695](https://www.sz003.com/codexh/2695)

不少人在 Codex 上吃过这个亏。界面汉化得好好的。关掉窗口再打开，又变回英文了。重新打一遍补丁，过两天重启，还是英文。像在跟补丁较劲。

问题多半不在汉化包身上。汉化补丁改的是本地文件，你要是按平时的方式直接启动 Codex，客户端在启动阶段会自己校验和更新文件，中文内容就被原版盖了回去。说白了，汉化本身没坏。是启动这条路绕开了它。

解法也直接，换一个带汉化启动的入口。我们这个 003 启动器就是干这个的。它把汉化工具和 CCSwitch 合进了同一个软件。装一个顶两个。

下载地址放在汉化启动页上：https://www.sz003.com/hanhua，Windows 版和 Mac 版都在这个页面，免费，也不用注册。

装好之后怎么用，往下看。

打开界面先看顶部。一行状态写着系统已支持、中文已设置，这两项都亮着，说明环境认好了。中间是线路和账号列表。底部有一个「重启中文 ChatGPT」按钮。以后启动就点它，启动器会带着汉化把客户端拉起来，关掉再开也是中文。补丁不用再手动打。

线路这块也顺手管了。以前切线路得单独开 CCSwitch。现在列表里直接选。3aic 线路启用后，余额和登录状态都在页面上看得见。切一次就生效。

两个提醒记一下。点重启按钮前，把没保存的活先收尾。按钮旁边写得很明白，重启会关掉当前客户端窗口。另外账号列表里的 OpenAI 官方账号，会跟着 Codex CLI 的登录状态走。显示异常就先重新登录一次，再切线路。

一句话收尾：汉化反复失效，别在补丁上较劲。换个带汉化启动的入口，这事就翻篇了。
