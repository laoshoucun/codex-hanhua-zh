# Codex 汉化包会不会动官方文件：三条线看明白

> 原文链接：[https://www.sz003.com/codexh/2683](https://www.sz003.com/codexh/2683)

装一个来路不明的工具，最怕的是它偷偷把官方文件改了，这个担心不是多余的。社区里流传过一些改包方案，做法是直接改客户端解包出来的 app.asar，顺带绕过签名校验。功能上确实能出中文，代价是把官方客户端的完整性破坏了，哪天出了别的问题，都说不清是谁的责任。

站上这个汉化专题提供的汉化包走的是另一条路，区别就在三条线上。说清楚这三条，你自己就能判断。

第一条线，不碰官方客户端本体

不重新分发，不替换，不重打包。官方客户端装在哪还是哪，文件名、大小、校验都不变。

客户端照旧由 OpenAI 或者微软商店更新，走的是官方通道。

第二条线，要改的只有配置里的一项

桌面端读语言的地方，认的是配置里 desktop.localeOverride 这一项。工具做的就是在启动之前把这个值写成 zh-CN。

配置项是官方自己留的入口，写它不涉及改程序文件。

第三条线，只读数据不执行程序

工具联网只做两件事：读一份 HTTPS 的 JSON 清单，读几张受限的图片资源。清单用来判断版本适配，图片用来显示状态。

它不下载脚本，不执行远端程序，也不往你机器上落二进制文件。这一条其实最好验证，装完之后看客户端目录有没有多出来的文件，看启动过程有没有额外的网络动作，都能对上。

怎么自己核对一遍

看客户端安装目录里有没有被替换过的文件，官方原文件的大小和修改时间应该保持原样。

再看工具里的日志目录，正常的流程只会留下配置写入和清单读取这两类记录。出现别的动作，就不用犹豫了。

一句实在话

界面变中文这件事，不用拿客户端的完整性去换。三条线都守住，官方更新照走，汉化该来的还会来。
