# Codex 汉化包怎么下载安装：先认清你装的是哪个客户端

> 原文链接：[https://www.sz003.com/codexh/2681](https://www.sz003.com/codexh/2681)

Codex 汉化包下载回来装完没反应，十有八九是版本或者渠道对不上。桌面端在 Windows 和 macOS 上有好几种装法，汉化工具要先能认出你机器上那一个，后面的事才谈得上。

先分清你装的是哪一种客户端，再说汉化包从下载到生效的实际走法。

先确认你机器上是哪一个客户端

Windows 这边有两种。一种是从微软商店装的，应用列表里能看到商店的来源标记。另一种是传统的安装包，装完一般落在 Program Files 下面，快捷方式自己建的。

macOS 这边常见两个名字，ChatGPT.app 和 Codex.app，从官网或者别处下的都可能遇到。

分清楚这一步的实际用处在这里：汉化启动是去识别本机已经装好的官方客户端，认出来才能接着往下走。版本或者渠道对不上，工具也帮不上忙，这也是很多人卡在第一屏的原因。

汉化包做的是哪一件事

它不改官方客户端。文件不替换，安装包不重新打，官方的那套东西原样放着。

它做的事只有一件，启动之前把 desktop.localeOverride = "zh-CN" 写进官方配置，让客户端启动的时候读到中文。写完之后，OpenAI 的更新、微软商店的更新都照旧，该升升，不影响。

Windows 版怎么下载怎么装

汉化包在站上的汉化专题里，Windows 版下载和 MacOS 版咨询是两个入口。

Windows 走的是下载这一条。拿到安装包之后运行，工具会去识别本机的客户端，读到版本，再去对一遍兼容清单，对上了就按中文启动。第一次跑完，界面上会给出适配状态，告诉你这次是不是匹配上了。

macOS 走的是咨询这条路

macOS 上客户端形态多，商店和官网下来的还不完全一样，所以这里没做成一个安装包甩出去，走的是客服协助。页面上那个 MacOS 版咨询的按钮点开就是客服入口，把版本号报过去，对面会告诉你适配情况。

装完怎么看生效没生效

界面变成中文，就是生效了。菜单、设置页、侧边栏这些地方最直观。

没变的话，先看工具里给出的适配状态。状态里写着未匹配，说明你的版本还没进清单，这时候重装也没用，等清单更新更直接。状态正常但界面还是英文，可以翻一下日志目录，再联系客服把日志一起发过去。

下载之前先做的一件事

打开客户端，找到 About，把版本号抄下来。带着这个号去汉化栏目查一遍清单。版本在里面，下载装完一次就能成。不在里面就把版本号放着，等清单更新。
