# Codex汉化包下载安装教程：中文版设置步骤，含汉化包导入方法

> 原文链接：[https://www.sz003.com/jiaocheng/2689](https://www.sz003.com/jiaocheng/2689)

Codex汉化包是一个给 ChatGPT 和 Codex 桌面端换中文界面用的小工具，完全免费，不用注册账号，也不用登录。Windows 和 macOS 都能装。

装之前先确认：电脑上得有官方客户端

汉化包不含官方客户端，也不代替它。它只做一件事，把官方客户端里本来就有的中文资源打开。所以你的电脑上要先有从官方渠道装好的 ChatGPT 或 Codex 桌面客户端，而且这个客户端本身能正常打开。

这一步安装器自己会查。本机找不到官方客户端，它不会继续往下装。

支持 Windows 和 macOS 双系统

下载入口按系统分了两个，Windows 版是 exe 安装包，macOS 版另外走一条线。打开 https://www.sz003.com/hanhua 就能看到这两个入口，按自己电脑的系统选。

下载全程免费，不用注册账号，不用登录，也不用填任何信息。macOS 版目前还没有独立的安装包，用的话联系我们协助。

下载下来的就是一个安装包，不用再去别处找语言包，也不用单独导入什么文件。

傻瓜化安装，一路下一步就行

双击下载好的安装包，一路下一步

它按当前用户装，不用管理员密码，也不会往系统目录里写东西

装完桌面上和开始菜单里会出现 ChatGPT汉化启动器

装完就能用，不用重启电脑，也不用另外配置环境。

一键切换中文：点一下按钮就够

打开启动器，它会先认机器上的官方客户端。认完把客户端版本写在状态条上，接着点界面中间那个按钮。

第一次打开，按钮上写的是「关闭并以中文工作台重启」。点下去官方客户端会被关掉，再以中文工作台重新拉起来

以后打开启动器，按钮上的字变成「重新启动中文工作台」，效果和第一次一样

按钮下方有一行提示，重启会关闭当前客户端窗口，点之前把手头的东西存一下。客户端重开之后界面就是简体中文。翻到设置里看一眼语言确认一下就行。

记得以后从启动器打开 Codex

Codex 官方客户端不支持永久汉化，重启电脑之后，界面就会恢复成英文。所以每次用的时候，记得从我们的启动器里进 Codex，它会把中文资源重新打开一次。

它平时待在系统托盘里，只有右键点退出才会真退出，关掉窗口不算。

完全免费，也不用注册登录

下载不收钱，装完也不收钱，没有试用期，也没有需要付费才能解锁的功能。不用手机号，不用邮箱，不用任何认证。装完打开就是能用的状态，省掉账号这一层。

官方一升级，汉化自动跟上

汉化失效基本都发生在官方更新之后，版本一变，之前配好的中文就对不上新的客户端。启动器每次启动前会先比一次官方版本，需要适配就自己更新。你这边不用重新找包，也不用重新下载重装。

不替换，也不重打包官方客户端

它不替换官方文件，也不重新打包客户端。它只是借官方自己留的那个运行时开关，把客户端里本来就内置的中文资源打开。所以官方客户端该更新照常更新，签名和校验都不受影响。装汉化不等于改客户端。

免费、不用注册登录、装之前先有官方客户端。这三点凑齐，装起来就没有坎。装完点一下按钮就是中文，以后每次记得从启动器打开 Codex。
