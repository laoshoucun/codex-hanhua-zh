# Codex 自主安装和中文汉化教程

> 原文链接：[https://www.sz003.com/codexh/2723](https://www.sz003.com/codexh/2723)

一、下载 Codex

官方下载地址：OpenAI Codex 官网

官方镜像下载（国内可直连）：安装包下载

Codex 安装好之后，这时候还不能用——原因大家都知道，它的服务在境外，需要特殊的网络环境才能访问，国内没法直连。所以下一步，我们还要装一个启动器。

二、下载 003 启动器

为什么要下载启动器？因为要访问国外的网站，就需要特殊的网络，而 003 启动器就是给大家选择上网线路用的；除此之外，它还支持汉化 ChatGPT 和 Codex。

启动器下载地址：汉化包下载页

如果你电脑是英文版本 Codex，从启动器左下角汉化入口进入就是中文版了。

三、充值使用

1、打开 003 启动器，点击右下角的算力中心。

2、注册一个账号，按页面提示填写相关信息即可。

3、创建一个密匙（后面导入启动器时要用到它）。

4、把密匙导入到 003 启动器中：如下面所示，选择导入到 ccs。

5、确认导入的密匙信息。

6、确认导入的供应商配置。

7、在启动器里选择 OpenAI 线路，就能看到咱们刚导入的线路了。为什么要选 OpenAI？因为咱们启动器支持多条线路，除了 OpenAI，还支持 Claude、Gemini、Grok 等，所以以后想用其它软件，也可以用咱们启动器来做路由。

8、到这里，所有准备工作就完成了，可以正常使用 Codex 了。当然，算力中心要有余额——Codex 的使用是需要付费的，大家点击算力中心自行充值就好。

9、算力中心有余额的情况下，就可以正常使用 Codex 了。我们来跟它说句话，比如发一句：你好。
