# Codex 更新完汉化就没了：版本适配是这么回事

> 原文链接：[https://www.sz003.com/codexh/2682](https://www.sz003.com/codexh/2682)

官方更新一次，界面回到英文，这种事在汉化用户身上挺常见。有人以为汉化被官方修掉了，其实不是，多半是版本变了，汉化跟不上了。

先讲它为什么会被更新打断，再说怎么少折腾。

官方一升级，界面就回英文

汉化是照着客户端某个版本做的对应关系。客户端升到新版本，界面代码动了，原来那套对应关系不一定还成立。这时候硬往上套，结果可能不是英文，而是半中半英，或者有些地方显示错乱。

所以现在的做法是版本对不上就不动，保留官方原来的界面，等清单更新。

版本适配是怎么走的

启动之前，工具读一下本机客户端的版本号，拿这个号去查一份兼容清单。清单里有，就按中文工作流走。清单里没有，就什么都不改。

还有一层是缓存。本机版本没变化的时候，优先用本机已经存下的结果，不必每次开机都去远端拉一遍。这样断网也能启动，省得等。

有人重装一次就好了，说明什么

仓库里有个 issue，编号 25417，环境是 Windows 的微软商店版，版本 0.135.0-alpha.1。报告里写的情况是首次安装之后，配置里明明有 localeOverride = "zh-CN"，界面还是英文，卸载重装之后恢复了。

这条记录有用，它说明安装状态本身也会影响读取，首次安装的某些路径和重装之后不完全一样。所以碰到没生效，先别急着把工具卸了装、装了卸，先确认版本对不对。

更新之后按顺序做的几件事

更新完先把版本号看一眼，这是第一步。版本号拿去对清单，在清单里就直接重启客户端，一般就回来了。

汉化包和这份清单都放在站上的汉化专题里，版本号对着看一眼，就知道自己有没有跟上。

不在清单里，就把版本号记下来等适配。这段时间界面是英文，不等于客户端出问题，日常该怎么用还怎么用。

适配清单是跟着官方版本节奏走的。官方连着发版的时候，清单更新会滞后几天，急不来。

别做的一件事

不为了汉化去装旧版本的客户端。旧版本拿不到新的模型和修复，捡了芝麻丢了西瓜。版本往前走，汉化跟着走，这样更顺。
