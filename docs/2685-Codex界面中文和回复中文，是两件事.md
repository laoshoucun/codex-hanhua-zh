# Codex 界面中文和回复中文，是两件事

> 原文链接：[https://www.sz003.com/codexh/2685](https://www.sz003.com/codexh/2685)

很多人以为界面切成中文，它回话自然也是中文。在 Codex 上这两件事是分开的，分开之后反而好办：界面可以慢慢等官方，回复语言你今天就能定下来。

界面语言是菜单和按钮那一层

菜单栏、设置页、提示框里的文字，属于界面语言。它由客户端自己带的那套语言资源决定，跟模型没关系。

这一层现在的情况是资源有，加载的口子没开，所以才要借汉化工具把配置写进去。

回复语言看你怎么跟它说话

你打字问它，它回你一段，这段内容由模型生成。用什么语言回，看你的提示词。你用中文问，它多半用中文答。想让它稳定用中文，就把它写进长期规则里。

命令行这边，本地 .codex 目录下放一个 AGENTS.md，里面写清楚用简体中文回复，之后每次启动都会带上这条规则。

桌面端可以在自定义指令里加一句同样的要求，效果一样。

只改了界面，回复还是英文

这种情况偶尔会碰到。界面已经是中文了，回答还是英文。原因一般是问法本身用了英文，或者历史会话里一直是英文语境。

处理办法简单，问的时候带一句请用中文回答，新开一个会话更干净。

两个都要中文怎么弄

界面这一层，装个汉化包把配置写进去，重启客户端看菜单有没有变。装法在站上的汉化专题里，一眼就能找到。

回复这一层，把长期规则写上，配一次长期有效。

两层各管各的，互不打扰。真要说先后，回复语言更值得先弄，你日常打交道的是它的回答，不是菜单。

兜底的一个判断

界面还是英文但回答是中文，说明模型这层没问题，只是客户端没读到中文资源。反过来，界面中文、回答英文，那是提示词没约束住。两种现象看着像，根子不在同一处，分开处理就行。
