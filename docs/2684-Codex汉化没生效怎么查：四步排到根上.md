# Codex 汉化没生效怎么查：四步排到根上

> 原文链接：[https://www.sz003.com/codexh/2684](https://www.sz003.com/codexh/2684)

Codex 汉化包装完，界面还是英文，先别卸。这类问题基本落在四个地方，按顺序走一遍，哪一步卡住就是哪一类原因。

版本对不上是最常见的一种

客户端关于页面里能看到版本号，先把它拿出来，去汉化栏目的清单里对一遍。版本不在清单上，后面几步都不用做，等适配就行。

版本在清单上，界面还是英文，往下一步走。

适配状态和日志里能看出卡在哪

工具跑完之后会留下一个适配状态，写着匹配或者未匹配。状态是未匹配，基本就是清单没覆盖，跟机器环境关系不大。

状态正常，就去看日志目录。日志里能看到配置到底有没有写进去。写进去了但界面没动，问题在客户端读取那一段。

网络不稳的时候会退回缓存

适配清单和部分资源要联网取。取不到的时候，工具退回本机缓存，界面可能保持原样。

这种情况的典型表现是第一次装完没反应，过一会儿再启动就好了。网络不稳的话，等网络正常再跑一遍就行。

变成中文了还乱码，是编码的事

界面已经中文了，但字变成方块，或者干脆认不出来，这不是汉化的问题。终端或者编辑器的编码还停在老设置上，把它调成 UTF-8 就正常。

CLI 里出现乱码，多半也是同一类原因，跟桌面端汉化没关系。

四步走完还是不行

把版本号、适配状态、日志目录里的记录一起发给客服。这三样齐了，对方一眼能看出卡在哪。只发一句没生效，来回问几轮反而慢。

汉化包和适配清单都放在站上的汉化专题里，客服入口也在那一页。
